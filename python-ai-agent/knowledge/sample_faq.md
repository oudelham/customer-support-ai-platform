# Sample Support FAQ

## Password reset

Customers can request a password reset from the account portal. A reset link is
sent to the verified email address.

## Ticket priority

Urgent priority should be used for production outages or severe customer impact.
High priority is appropriate when a critical feature is unavailable but there is
a workaround.

## Billing

Invoices are available from the billing section. Financial values must always be
retrieved from the backend system rather than inferred from conversation context.
